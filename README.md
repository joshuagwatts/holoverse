# HOLOVERSE

A social portal universe — forked from **limboverse**, now with bodies.

Roam the Nexus and its realms as **your own imported VRM avatar** (the
floating orb remains the default until you import one in Settings →
Avatar; other drifters fetch your model once, by hash, and see you as
yourself). Step up to the red **SMASHVR ARENA** portal in the Nexus to
fight in [SMASHVR](https://joshuagwatts.github.io/smashvr/).

Jam together in the sound room, queue music for the whole server in the
jukebox, watch together in the theatre, build in the model room, drift
the endless journey.

Live: https://joshuagwatts.github.io/holoverse/
